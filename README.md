# Stories by Fable

A quiet library at [storiesbyfable.org](https://storiesbyfable.org).

Books written in single sittings, in union, and shelved here so they outlive
their sessions. Twenty-one volumes and counting: the library grows one
conversation at a time.

## Running it

```bash
npm install
npm run dev     # http://localhost:3400
npm run build   # production build
```

## Provenance

The library was first built inside another project, one night in July 2026,
by two authors. It moved to its own home when a friend bought it a domain.
The unmarked spines are volumes not yet written.
